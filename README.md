# 白话 SEO

**写给独立开发者和站长的搜索流量课** · 作者：Tony Wu

用大白话讲透 SEO：从搜索引擎的原理、选词、建站、内容、外链、数据，到 AI 搜索时代的 GEO。写给会做产品、不会做流量的人。

全书前言 + 7 篇 31 章，贯穿案例是独立开发者阿哲和他的工具站——从挖到第一个词，一路做到被 ChatGPT 引用。每章配 SVG 解释图、翻车现场与 Kata 练习。
